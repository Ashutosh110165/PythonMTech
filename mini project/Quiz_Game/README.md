## Mini Project

### Title
Python Quiz Game

### Description
The Python Quiz Game is a web-based quiz application developed using Flask. It allows users to answer multiple-choice Python programming questions, calculates their score, displays their performance, and stores the results in a text file.

### Features

- User name input
- Randomized quiz questions
- Progress bar
- Multiple-choice questions
- Score calculation
- Percentage calculation
- Correct and incorrect answer count
- Performance message
- Play Again option
- Score history stored in `scores.txt`

## Technologies Used

- Python
- Flask
- HTML
- CSS

## How to Run

1. Install Flask

```bash
pip install -r requirements.txt
```

2. Run the application

```bash
python app.py
```

3. Open the browser and visit

```
http://127.0.0.1:5000
```
